# Noto Serif

This directory contains the upright and italic Noto Serif variable fonts embedded by the `pdf` crate. They provide a
stable, broadly Unicode-capable typeface for generated legal documents without requiring fonts on the host machine.

It serves PDF rendering only; Navigator's web fonts are separate deployment assets. The files come from Google Fonts and
are distributed under the SIL Open Font License 1.1 in <OFL.txt>, preserving the provenance and permission needed to
ship them inside the renderer.
