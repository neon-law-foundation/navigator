# Project repositories

`repos` manages the bare git repository attached to each Navigator Project. It creates, reads, and advances one
append-only `main` branch and provides the narrowly governed path for lawful expungement.

It serves matter collaboration and audit features in `web`. Git history is necessary because a Project's working files
need a durable, attributable version trail; repository-level guards prevent clients from rewriting, deleting, or
branching that history through ordinary pushes.

See [project repositories](../docs/project-repositories.md) for transport, authorization, storage, and expungement
design.
