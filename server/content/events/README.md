# Nebula events

This directory contains the reviewable Markdown used to publish Neon Law Foundation Nebula show-and-tell pages.
Navigator owns the editorial copy, schedule, image, and outbound event link; Luma owns attendance, registration, and
calendar data.

It serves Foundation editors and event visitors. Keeping registration outside Navigator avoids storing attendee data,
while versioned content lets the public site reliably distinguish upcoming and past events.

Event files use dated filenames and typed frontmatter and may not also declare a Notation workflow. See
[frontmatter](../../../docs/frontmatter.md) for the content contract; the `navigator validate` command enforces it.
